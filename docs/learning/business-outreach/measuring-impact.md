## Overview

Judges and sponsors hear “we inspired hundreds of students” every weekend.
The teams they remember are the ones who can say *how many, where, doing
what, measured how*. This lesson is the evidence habit that makes later
award work possible.

## Prerequisites

- [Planning Outreach Events](../outreach-events/)

## What you'll learn

- Which numbers are worth collecting.
- How to capture stories without turning people into props.
- How to keep a running file instead of reconstructing April from memory.

## Unit 1 — Count the things you can defend

Useful metrics are specific and repeatable:

- **People** — unique students, teachers, families, other teams. Say how you
  counted (sign-in, teacher headcount, not “the gym looked full”).
- **Hours** — student hours and mentor hours, separately.
- **Depth** — a 5-minute hallway demo is not the same as an 8-week mentor
  relationship. Tag the type.
- **Repeat** — first-time vs. returning partners.

Vanity metrics (likes, “reach”) are optional garnish. Do not lead with them.

## Unit 2 — Stories with consent

A good story has a person, a change, and a quote they approved:

- Get permission to use names and photos, especially of minors.
- Write the story the same week. Memory invents adjectives.
- Prefer “what they can now do” over “they were so excited.”

## Unit 3 — The running file

Keep one shared folder with:

- Event briefs and attendance.
- Photos with captions (who, where, date).
- Thank-you emails and partner contacts.
- A one-line log after every event: goal, count, what we would change.

This file is the raw material for [The Impact Award Submission](../impact-award/).
If you start it in March, you are already late.

## Steps & acceptance criteria

- [ ] Log one past or upcoming event with people, hours, type, and source of
      the count.
- [ ] Write a 6–8 sentence story with a consented quote, or note why you
      cannot use one yet.
- [ ] Create (or add to) the shared impact folder with a consistent file
      name.
- [ ] Explain the difference between a headcount and an estimate.
